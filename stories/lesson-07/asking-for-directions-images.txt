Image prompt for 《捷運站在哪裡？》Where Is the MRT Station?
6 turns → 3 columns × 2 rows. Turn count follows
the source text — never adjusted to suit a grid.

HOW TO USE THIS FILE — generate ONE image, then edit it twice, all in the
SAME chat:
  1. Paste the IMAGE PROMPT — EASY block. This generates the base picture.
  2. Paste the IMAGE EDIT PROMPT — MEDIUM block right after, in the same
     chat. This asks the model to edit the image it just made — same
     artwork, only the bubble text changes — instead of drawing a new one.
  3. Paste the IMAGE EDIT PROMPT — HARD block the same way, still in the
     same chat (it edits the EASY image again, not the MEDIUM one, so
     changes don't stack).
Editing preserves far more of the actual picture than a fresh generation
does, because the model is transforming an image it can see rather than
reconstructing the scene from text. If your chat doesn't carry the image
forward (a new conversation, a different device), upload the EASY image
file before pasting the edit prompt.

This still will not produce byte-identical artwork across all three — an
edit can nudge a line or a colour. For that, use the local compositing
route in SKILL.md step 12 instead.

(Chinese text in AI-generated images is unreliable — proofread every
speech bubble against the CAPTION SCRIPT under each prompt and regenerate
if any characters look wrong.)

Every panel is EXACTLY THE SAME SIZE: identical width, identical height, each

two cells, no panel may be larger than another, and a panel's size does not

ONE PANEL = ONE LINE. All 6 lines listed below must appear, each alone in
its own panel, in reading order.
A panel whose line is spoken gets ONE simple rounded speech bubble — plain
white with a black outline and a small tail pointing at the character named
below. A narrator panel gets ONE rectangular caption box (no tail) along the
bottom edge instead. Never two in a panel, never a panel without one. Write
only the quoted Chinese inside a bubble; never write the speaker's name in it.

Make the bubbles and boxes generously sized — roughly the top third of the
panel, with the characters composed into the lower two thirds (this story's
HARD lines are the longest — leave room for them even though this is the EASY
image, since the next two prompts reuse these same bubble positions). No other
text anywhere in the image: no title, no level label, no panel numbers, no
signage, no letters of any alphabet outside the bubbles and boxes.

COUNT CHECK — before finishing, count the panels: exactly 6 panels, filling
the 3×2 grid. If a line has nowhere to go, a panel has been dropped: add
it back rather than merging two lines into one bubble. Panel 6 is the ending
of the story — a page without it is not the story.

Flat digital illustration style, soft rounded shapes, warm morning colour
palette, limited colour palette, gentle clean outlines, friendly simple
style, consistent lighting and colour across every panel.
